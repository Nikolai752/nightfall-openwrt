# История изменений Nightfall

## v1.0.20 · Кнопки в боте, блокировка устройств, отчёт
- Бот в Telegram теперь управляется кнопками под сообщениями: `/menu` открывает меню (Статус, Клиенты, Трафик, Приложения, Скорость, Блокировка, Перезагрузка). Команды тоже работают.
- Блокировка устройств: у выбранного устройства отключается выход в интернет (по MAC-адресу, отдельная таблица nft `inet nightfall`; сам роутер и локальная сеть остаются доступными). Кнопками в боте и в новой карточке «Доступ в интернет» на странице «Обзор».
- Расписание блокировки: «с … до …» каждый день, можно через полночь (например 23:00–07:00). Правила применяются при старте и раз в минуту.
- Ежедневный отчёт в Telegram: настройка «Ежедневный отчёт, время» (например `21:00`, пусто = выключен): трафик за сутки, топ устройств и приложений, предупреждения, температура.
- Перезагрузка роутера из бота с подтверждением, только владельцу.
- После обновления выйдите и войдите в LuCI снова: добавлены права на `nightfall-block`.

## v1.0.19 · Команды боту и новый README
- Бот в Telegram понимает команды: `/status`, `/clients`, `/traffic`, `/apps`, `/speed`, `/help`. Отвечает только владельцу. Меню команд появляется в Telegram само.
- Команды можно отключить параметром `TG_BOT=0` (поле «Команды боту» в настройках монитора).
- README (русский и английский) обновлён под все новые возможности.

## v1.0.18 · Из чего состоит «Прочее»
- В карточке «Трафик по приложениям» под строкой «Прочее» показываются самые тяжёлые неопознанные домены (cloudfront.net, example.co.uk…) и прямые адреса без имени.
- По этим доменам можно добавить свои правила в `/etc/nightfall-apps.list`: `Название|домен1 домен2`.
- Данные «Прочее» накапливаются с момента обновления: за прошлые дни разбивки не будет.

## v1.0.17 · Telegram через VPN
- Для Telegram можно указать интерфейс VPN (например `wg0`): запросы пойдут через него, если api.telegram.org закрыт напрямую.

## v1.0.16 · Исправление Telegram
- Кнопки «Определить chat id» и «Отправить проверку» теперь имеют нужные права доступа и работают.

## v1.0.15 · Telegram-уведомления и новые устройства
- Уведомления в Telegram: пропал и вернулся интернет, перегрев, мало памяти, переполнение флеш, роутер перезагрузился.
- Новые устройства: когда в сети появляется незнакомый адрес, запись попадает в ленту событий (и в Telegram, если он включён). Известные устройства запоминаются, повторов нет.
- Настройка в «Монитор ресурсов» → История → Настройки: токен бота, кнопки «Определить chat id» и «Отправить проверку», прокси для Telegram.
- Нужен curl: `apk add curl`.

## v1.0.14 · Ровная карточка приложений
- В карточке «Трафик по приложениям» полосы выровнены в одну линию независимо от длины чисел.

## v1.0.13 · Трафик по приложениям
- Новая карточка «Трафик по приложениям» на странице «Обзор»: сколько скачали YouTube, Telegram, Netflix, Google и другие, за сегодня, 7 и 30 дней.
- Можно смотреть общий итог или по каждому устройству.
- Учёт включается кнопкой в карточке: включается журнал DNS dnsmasq (в памяти роутера), выключается там же с возвратом прежних настроек.
- Свои правила (сервис → домены) можно добавить в `/etc/nightfall-apps.list`.
- Данные приблизительные: трафик через VPN и шифрованный DNS (DoH/DoT) определить нельзя; с включённым Flow Offloading счётчики могут занижаться.

## v1.0.12 · Компактная нижняя панель
- Кнопки «Применить», «Сохранить» и «Сброс» теперь в одну строку и в 4–5 раз ниже (было до 230 px, стало около 50 px).
- Размеры подстраиваются под ширину экрана: от маленьких телефонов до Pro Max.
- В горизонтальном положении панель не закрывает экран, а встаёт в конец страницы.

## v1.0.11 · Подпись релизов
- Релиз подписывается ключом usign, роутер проверяет подпись перед установкой и отклоняет архив с неверной подписью.
- Открытый ключ ставится вместе с темой: `/etc/nightfall-release.pub`.

## v1.0.10 · Проверка обновления из интерфейса
- Тестовый выпуск: проверяет, что окно «Доступна новая версия», установка и «Что нового» работают.

## v1.0.9 · Обновление из интерфейса
- Окно «Доступна новая версия»: роутер сам скачивает релиз, проверяет контрольную сумму sha256 и устанавливает его.
- При ошибке установки файлы возвращаются из копии, прежняя версия продолжает работать.
- После установки сессия перезапускается, а после входа показывается список изменений.
- Для скачивания на роутере нужен curl: `apk add curl`.

## v1.0.8 · Обзор без мигания
- «Состояние портов» больше не моргает между «нет связи» и «нет соединения».
- Список подключённых Wi-Fi клиентов не подпрыгивает при обновлении.
- Карточки Обзора раскладываются в 2 колонки от ширины окна 900 px.

## v1.0.7 · Скорость и тестовая страница
- Замер скорости работает на быстрых каналах (несколько потоков).
- Исправлено дёрганье таблицы подключённых клиентов.
- Новая страница «Nightfall: все элементы» для проверки темы.

## v1.0.6 · Исправления на телефоне
- Кнопки в настройках, журнал перезагрузок и заголовки вкладок приведены к общему стилю.
- Панель на вкладке «Обзор» не дёргается при автообновлении.
